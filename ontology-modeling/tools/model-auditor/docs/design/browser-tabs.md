# 浏览器多标签页审计设计

面向审计器的使用者、实现者和测试者。本文定义 Cmd + 点击内容链接、新标签页接入同一工作区、审阅同步与异常处理的设计契约；不是已实现功能的使用说明。结构为目标与现状、交互、共享工作区、一致性、运行与安全、实现边界、验收。

## 1. 目标与现状

已确认的要求：

- Cmd + 点击打开浏览器标签页，不是审计器内部标签。
- 覆盖全部内容导航；新旧页面显示同一工作区，审阅结论和备注共享同步。
- 允许离线本地服务，模型不发送给服务端；架构选择见 [ADR 索引](../adr/README.md)。
- 实现状态：共享运行时、真实路由和页面交互已接通；自动门禁覆盖核心、端口、打包 DOM 与干净分发。macOS Chrome/Safari 的原生浏览器验收仍未完成，使用步骤和运行边界见 [README](../../README.md)。

当前源码的事实：

- `app.js` 只持有本页路由和视图状态，HTTP 通过 `connectSharedWorkspace` 接入，`file://` 通过显式本地适配器复用同一核心，不向共享页面复制完整索引。
- 全部内容导航使用 `a[href]`；普通原文点击保留当前定义/视图，`sourceKey` 保存独立原文所属定义，修饰点击不导航或激活原页。
- `review-ui.js` 预登记并持续持有编辑租约，字段 CAS 单在途并保护组合输入；`session-ui.js` 协调全局屏障、最新 R 确认、完整下载和保存确认。
- `workspace-host.js` 使用可退休的有界回执窗口、活跃候选/下载释放和完整导出游标；`whenReady`/`onState` 公开重同步就绪，不依赖 sleep。显式 LEAVE 回收身份，新会话 nonce 拒绝旧命令。
- `build.mjs` 分批发布同版本 HTML/worker/manifest，当前版本资源保持 Git 可见；`distribution.test.mjs` 验证不带 node_modules/历史构建的 Node-only 分发。替代集成不等同于原生 SharedWorker/CSP、标签寿命或下载验收。

设计不增加模型编辑、远程协作、持久化恢复或语义 diff，也不改变基础检查的覆盖范围。

## 2. 交互契约

### 2.1 链接与操作分离

多页共享模式的内容导航必须是带有效 `href` 的 `<a>`，不能只给按钮添加 `metaKey` 判断或依赖 `window.open()`。原生链接同时提供右键新标签页、复制链接和中键行为；是否前台激活由浏览器偏好决定，不强制调用 `focus()`。

| 入口 | 普通点击 | Cmd + 点击后的新页 |
| --- | --- | --- |
| 侧栏定义、显式模型引用、关联卡片的“打开完整定义” | 当前页显示目标定义 | 同工作区中显示目标定义 |
| 顶栏工作台、问题清单、权限矩阵、导入文件 | 当前页切换视图 | 同工作区中打开对应视图 |
| 对象聚合／审计摘要、全部字段、引用关系 | 当前页切换定义视图 | 打开同一定义的指定视图 |
| 原文定位、问题原文定位、M4/M6 局部引用 | 保留当前页的原文面板交互 | 打开原文所属定义，展开面板并定位准确字段／局部步骤 |

未找到或存在歧义的引用继续显示非导航提示，不能生成“随便选一个定义”的链接。展开卡片、分页、搜索、筛选、原文面板开关、导入、清空、加载示例和导出仍是操作控件，不因 Cmd 修饰键重复执行。

点击增强只拦截未被处理的、无修饰键的左键同应用导航。Cmd、Ctrl、Shift、Alt 与中键交还浏览器，不执行当前页导航；macOS 的 Ctrl + 点击也由浏览器处理其上下文菜单。键盘 Enter 激活链接、浏览器后退／前进和复制地址必须可用。

### 2.2 页面之间互不牵动阅读位置

每个页面独立保存选中定义、当前视图、搜索与筛选、分页、卡片展开、主内容滚动、原文滚动和面板开关。共享审阅更新不能把另一个页面带到修改者正在阅读的位置。

新页由链接指定目标视图；不复制原页面的临时搜索、滚动和展开状态。标签标题显示目标定义或视图名称，方便区分多个审计页面。原文面板必须明确标出“原文所属定义”和“当前填写审阅的定义”，不能把其他定义的备注写到当前定义下。

### 2.3 可链接地址

统一路由包含协议版本、随机工作区标识、接入凭证、数据集版本、页面类型，以及可选的定义键、定义视图和原文字段路径。使用 URL fragment，接入凭证与定位参数不发送给静态服务；URL 不包含 YAML 正文或审阅备注。

定义键由文件路径、原文件 SHA-256、模型 section 与定义在文件中的路径生成稳定摘要；同文件中的重复业务 ID 也必须可以区分。局部步骤、活动和字段定位都附着于所属定义，不能跨场景／流程误解析。字段路径按类型编码，保留数字索引与字符串键的区别，解析时校验自有属性、深度与边界。

定位信息可能进入浏览器历史；编码不是加密。链接只在同一浏览器 profile、同一 origin、同一存活工作区中有效，不承诺跨浏览器、跨设备或退出后恢复。

URL 是阅读位置的唯一导航来源，普通点击、浏览器历史与首次启动共用解析／应用逻辑。原文的普通点击可保留当前上下文，但需将面板焦点同步写入当前页地址；其 `href` 描述在独立新页打开目标原文的完整视图。

`sourceKey` 是可选的独立原文定义键；`key` 仍明确当前审阅所有者，`path` 附着于 sourceKey 或默认 key。顶栏切换保留当前审阅定义和原文对照；非定义页也可携带明确审阅所有者。旧版不带 sourceKey 的路由继续有效，所有目标和路径分别校验。

旧 `#model=` 地址只在模型已导入且目标匹配唯一时转换；无匹配或多匹配必须显示提示。带工作区标识的过期链接不能自动创建空工作区、转到首个定义或按相同业务 ID 猜测新版本目标。

## 3. 共享工作区

### 3.1 所有权与状态边界

采用同 origin、固定版本 URL 与 worker 名称的 SharedWorker。各标签页用独立 MessagePort 接入；不用 `window.opener`，不选举主页面，也不以 BroadcastChannel 的消息广播代替状态所有权。

```text
浏览器页 A ─┐
浏览器页 B ─┼─ MessagePort ─ SharedWorker：工作区、模型、审阅与提交序列
浏览器页 C ─┘
本地静态服务：只提供页面和 worker 资源，不接收模型或备注
```

| 状态 | 所有者 | 同步方式 |
| --- | --- | --- |
| 文件内容／指纹、模型索引、检查结果、数据集版本 | worker | 接入时发送版本元数据；模型内容按当前视图有界查询 |
| 审阅结论、备注、字段修订号、导出水位 | worker | 经确认的增量通知，读取所需字段 |
| 输入中的草稿、冲突内容、尚未确认请求 | 各页面 | 本地保留；不得冒充已同步状态 |
| 路由、搜索、展开与滚动 | 各页面 | 不跨页同步 |

独立打开应用首页创建新工作区；从内容链接打开才接入已有工作区。多个工作区隔离，不能仅按业务 ID 合并。接入凭证由安全随机数生成，worker 不提供枚举或猜测接入能力；这不是对同 origin 恶意脚本的安全隔离。

worker 名称由构建标识与工作区标识确定，不能为每页随机取名。仅没有工作区地址的首页可用全新标识发起 CREATE；带工作区地址的新页只能 JOIN。JOIN 若遇到无已初始化状态的新 worker，必须报告工作区过期并关闭本次连接，不能将“构造器新建了 worker”误当成“恢复了旧工作区”。

新页完成协议／构建版本握手、接收一致快照、应用后续增量，再显示可编辑状态。快照标记序列 S，接入期间 S 之后的变更必须排队交付；缺号、重复、旧版本和乱序要显式处理，不能“快照之后刚好没消息”地丢更新。

### 3.2 数据与通信契约

- 解析、建索引、检查与权威审阅状态在 worker 内执行。跨页使用结构化克隆的显式 DTO，不直接发送带函数、循环引用的当前 index。
- 页面不持有整套 YAML／索引副本，只缓存当前视图所需的有界 DTO、已收到的审阅值与本页草稿。DTO 以稳定键关联定义和目标；原文按段查询并保留别名定位，列表和嵌套字段按现有分页返回。新增页面不能导致全量模型重新解析或克隆。
- 握手携带协议与构建版本。所有写命令携带请求 ID、客户端 ID、工作区 ID、worker 实例标识和数据集版本；worker 再校验端口权限、字段类型、尺寸与当前状态。
- 写操作串行提交；请求 ID 去重，断线重连后的重试不能重复修改。事件使用单调序号；页面只应用所属工作区和当前数据集的事件。
- 每个端口必须采用有界待确认窗口或等价背压，慢消费者不能让 worker 无限积累消息；超过窗口后将该客户端标记为需要重新同步，保留其本页草稿。不能静默漏事件、删除工作区或把后台冻结当作同意全局变更。
- 审阅变更通知、计数和修订号使用小型增量；需要的正文按订阅读取，不在每次按键重传 YAML。首次快照是工作区版本／文件指纹／统计／审阅水位等元数据，分批收齐后再按路由查询视图；不包含整套原文和索引。视图响应带数据集版本及请求号，旧响应不能覆盖新页面。
- 文件读取只发生在用户选择／拖放的文件上；传给 worker 的输入使用 `{path, bytes}`，不要依赖 structured clone 保留 `webkitRelativePath`。既有大小、编码、结构与别名限制继续生效。

### 3.3 工作区寿命

关闭创建工作区的页面不产生特殊效果；仍有正常接入页面时可以继续审阅。刷新页尝试重新接入相同工作区，接入成功才恢复编辑。所有页面关闭、浏览器退出、worker 被系统回收或崩溃后，不承诺恢复；最后一页单独刷新也可能失去内存工作区。

后台页面可能被冻结，不能用短心跳超时判定其已经关闭，更不能据此自动删除工作区或确认破坏性操作。worker 存活性、页面回收与浏览器支持必须通过真实浏览器验证；不得宣传为可靠持久化。

一旦检测到失联，页面禁用共享写提交；检测滞后时也只有 worker 确认才能把草稿标为已同步。已收到的视图、审阅值与本地草稿留在页面内，可显式导出带版本、指纹和不完整标记的恢复副本；它不等于全工作区快照。不得把失联页面提升为权威源或自动向新 worker 恢复旧状态。过期链接提供重新导入入口；创建新工作区必须是用户操作。

## 4. 一致性与数据保护

### 4.1 结论与备注并发修改

审阅按定义键保存，结论和备注各有修订号。输入先成为本页草稿，再提交带基准修订号的字段更新；worker 的确认才表示已同步，定时防抖或输入框失焦都不能作为保存成功依据。

- 不同定义、同一定义的不同字段可分别提交，不互相覆盖。
- 同一字段从相同旧版本并发修改，只接受先通过版本校验的一次。另一页显示冲突，保留自己的草稿和最新共享值，要求选择最新值或合并后重新提交；禁止无提示地最后写入覆盖。
- 每个字段保持单个在途请求并合并其后的本页输入。确认旧请求时不能覆盖用户后来输入的内容；中文输入法组合期间不重绘或替换正在编辑的文本。
- 没有草稿的页面自动展示已确认更新；有草稿的页面保持光标与草稿，标记远端变更，不调用全页 `draw()` 重置阅读位置。
- UI 区分“待同步／已同步／冲突／连接中断”与“尚未导出”。已同步只代表浏览器内存已确认，不代表写入磁盘。

### 4.2 导入、清空与加载示例

这些操作影响整个工作区，必须明确提示“将影响所有已接入标签页，并清空共享审阅记录”。沿用当前成功导入重置审阅的语义，不自动迁移旧结论。

1. 在独立候选数据集中校验输入、解析、建立索引；失败时所有页面的当前数据和审阅不变。
2. 候选就绪后申请工作区变更屏障，固定参与页面集合：这些页面停止新增编辑，提交在途草稿或明确拒绝变更；存在冲突、未确认草稿、未响应页面或参与者离开时中止本次提交，不把超时当同意。新连接只读等待，不加入当前屏障。
3. 收齐确认后，向发起页展示最新审阅／导出状态，再确认全局重置。取消或发起页失联即释放屏障，候选不生效；等待超时只允许中止，不允许强制提交。
4. worker 校验候选的基准数据集版本与屏障状态，原子替换模型和审阅，增加数据集版本并广播提交。并行导入中只有一个基准仍有效的候选可提交，其余须重新发起。
5. 新接入页面在屏障结束前不获得写权限。暂停后恢复的旧页必须先核对数据集版本，旧写请求拒绝，未提交草稿保留为恢复内容。

模型变更后，不受影响且稳定定义键相同的当前视图可显式重定位到新数据集；字段路径仍须验证。定义消失或文件指纹改变时显示目标已过期，不能跳到同 ID 的另一个定义。浏览器历史中的旧数据集地址保留过期提示。

### 4.3 导出与离开页面

任一接入页可请求导出共享审阅。完整导出复用短暂的草稿屏障：参与页面暂停新增编辑并提交草稿，全部确认后截取序列 S，随即恢复编辑，不在等待用户保存时继续占用屏障。冲突或未响应时取消，或让用户明确选择只导出已确认快照并附带不完整标记；不得把未暂停新增输入的页面应答当作完整性依据。

worker 在序列 S 获取不可变快照；文件列表、指纹、定义键、位置和审阅必须来自同一数据集版本。导出沿用既有 provenance 字段，增加工作区／数据集／快照序列、稳定定义路径及完整性信息，格式版本升级。下载过程中新提交的审阅不能被 S 的导出覆盖为“已导出”。

导出水位使用 `(worker实例, 数据集版本, 审阅修订号 R)`，与消息序列 S 分开。只有审阅提交增加 R，导航、接入和导出确认不产生新审阅；dirty 比较当前 R 与已确认导出的 R。旧数据集／旧 worker 的下载确认拒绝，不能清除新工作区的未导出提示。

浏览器触发下载不等于文件已保存。界面先显示“已生成序列 S 的下载，请确认保存”，用户确认后才推进共享导出水位；恢复副本或不完整快照不能清除全局未导出提示。

关闭／刷新时，只要本页有未确认草稿，或共享审阅仍未导出，就保守触发离开警告；不依赖不可靠的“最后一页”计数。强制关闭、浏览器崩溃和系统回收不能保证警告或保全内存数据。

## 5. 运行方式与安全

多页共享模式通过本地 HTTP origin 运行；保留单 HTML 的原有单页能力，但不宣称 `file://` 支持共享。文件模式的 Cmd + 点击不能降级为当前页跳转，应明确提示先启动共享模式；SharedWorker 不可用或加载失败时也不静默降级为彼此独立的副本。

`node serve.mjs` 是只读共享服务入口，需要 Node.js 22+；启动和分发步骤见 [README](../../README.md)。服务只依赖 Node 内置模块，使用已打包的页面、worker 与清单，不要求安装构建／测试依赖。

运行约束：

- 只绑定 `127.0.0.1`；使用操作系统分配的端口并输出实际地址。同一工作区的所有链接保留完全相同的 scheme、host、port 和路径，不混用 `localhost` 与 IP。
- 只响应明确允许的静态页面与 worker 的 GET/HEAD；拒绝上传、非允许方法、目录遍历、其他 Host 和源码目录访问。不启动数据库、不读取用户模型目录、不接受模型／备注作为 HTTP 请求体。
- 模型字节仅从文件选择传入浏览器内的 MessagePort，不经 HTTP、WebSocket 或外网接口传输。不使用 localStorage、IndexedDB、Service Worker 或 Cache API 保存业务内容。
- 用独立、稳定 URL 的 worker 构建产物，不为每页创建不同 Blob worker URL。同一工作区必须连接同一脚本版本与名称；应用／worker 版本不一致时拒绝接入。
- 服务启动时校验并固定一整套构建资源，运行中不从变化的磁盘文件拼接新旧版本。HTML 与 worker 使用 `Cache-Control: no-store`、正确 MIME 与 `nosniff`；重启／升级前提示先导出，不宣称跨服务重启恢复。
- 同步调整 HTML meta 与 HTTP 响应的 CSP：只放行同 origin 的 worker，保留 `connect-src 'none'`，HTTP 头禁止被其他页面嵌入。不能只放开一处而被另一处策略交集阻止。
- 新页不依赖 opener；所有模型文本、链接属性和 URL 参数继续分别转义／校验。原文、伪代码、SQL 和表达式永不执行。

工作区链接含接入凭证，不应对外分享。fragment 不发送给静态服务，但可能出现在浏览器历史、复制地址或扩展访问范围内。内存模式不等于浏览器、操作系统或用户下载文件绝对不会落盘；工具不主动持久化模型和审阅内容。

## 6. 实现边界与改动面

源码职责拆分如下；真实浏览器的发布验收仍按第 7 节单独执行：

| 模块 | 职责 |
| --- | --- |
| `navigation.js` | 稳定定义键、路由编解码、真实链接生成、普通点击／历史增强 |
| `workspace-core.js` | 权威模型、审阅字段版本、串行命令、导出快照、变更屏障；不依赖 DOM |
| `workspace-worker.js` | SharedWorker 端口接入、凭证与版本握手、快照传输和订阅管理 |
| `workspace-client.js` | 有界视图缓存、请求／确认、草稿和冲突、顺序检查与恢复副本 |
| `snapshot.js` | 工作区元数据与有界视图 DTO 的编解码／校验，不传全量模型、函数或隐式对象图 |
| `serve.mjs` | 只读 loopback 静态服务及资源一致性校验 |
| 既有 `app.js` | 保留视图状态和 DOM 事件，使用有界查询结果渲染，移除对共享数据的直接写入 |
| 既有渲染文件 | 内容导航按钮改链接，保留分页／惰性展开，局部更新审阅 UI |
| 既有 parser／importer／indexer／checks | 复用现有解析与检查语义，增加稳定键与 worker 输入适配 |
| 既有构建与测试 | 同版本页面／worker／构建清单，分批暂存后整套发布，补跨页测试 |

单 HTML 单页模式通过显式本地适配器复用同一工作区核心；共享模式只用 worker 适配器。两种模式在入口处明确标识，不以 SharedWorker 异常作为自动切换信号。保留两种模式的构建和回归成本属于此方案的代价。

实现先锁定路由与工作区协议及其测试，再接入 worker 和静态服务，最后替换导航控件与审阅交互。完整功能包含全局破坏性操作协调、版本化导出和失联处理；不能只上线新开标签而把这些问题留作未声明行为。

## 7. 验收契约

### 7.1 可复现的自动化验收

| 组 | 必须验证的结果 |
| --- | --- |
| 原生导航 | 每类内容入口都提供可解析 href；修饰点击不改变原页路由、视图、滚动或展开；新页目标准确；右键／中键与历史可用 |
| 同工作区 | 新页无需再次选文件，指纹／定义／基础检查与原页一致；关闭创建页后其他页继续工作；单独打开首页不串工作区 |
| 视图隔离 | 一页搜索、切换定义、滚动、展开或定位原文，不改变另一页的阅读位置 |
| 首次接入 | 快照传输中同时发生审阅变更不会丢更新；乱序／缺号触发重同步，旧响应不能覆盖新路由或新数据集 |
| 并发编辑 | 同字段并发产生显式冲突且双方内容保留；不同字段可各自提交；在途确认不吞后续输入、光标和中文组合输入 |
| 全局变更 | 导入失败全部回滚；候选生成、屏障、确认期间的取消、失联、草稿、并行导入和新页接入不会误清空审阅 |
| 旧版本 | 文件替换、重复业务 ID、失效定义、旧字段路径、旧 worker 实例、旧数据集写请求不能误定位或误写 |
| 导出 | 任意页得到同一序列的一致快照；草稿／未响应页面使完整性明确；下载未确认、新编辑、恢复副本不能错误清除 dirty |
| 故障 | worker 加载失败、不可用、崩溃、端口断开、页面恢复和工作区过期均明确提示，不自动创建伪恢复工作区 |
| 安全 | HTTP 只有静态白名单请求；无模型／备注上传；不写业务持久化；错误 Host、路径遍历、恶意字段／hash、未认证消息被拒绝 |
| 慢消费者背压 | 接入或订阅中的页面冻结时，其他页持续编辑不会造成无限待交付队列；恢复后重新同步并保留本页草稿，不把冻结当成全局操作的同意 |
| 资源与回归 | 现有 28 项核心与 DOM 集成回归继续通过；元数据分批、内容有界查询，新页和输入增量不夹带全模型；单页模式保留原有能力 |

### 7.2 真实浏览器发布门槛

候选验收环境为 macOS Chrome 与 Safari 的实际版本，必须记录具体版本和结果后再声明支持。Chromium 自动化中的新 Page 不等于真实 Cmd + 点击；WebKit 自动化不等于 Safari 验收；jsdom 不能验证 SharedWorker、CSP、标签寿命或下载。
